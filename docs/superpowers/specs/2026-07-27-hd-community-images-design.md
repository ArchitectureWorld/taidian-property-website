# 泰典物业官网高清社区影像设计

## 目标

解决现有 `640×246` 社区图片被多处放大复用后出现的明显模糊问题，同时控制首屏下载体积，不改变纯静态部署方式。

## 影像方案

- 使用四幅不同的社区服务场景，分别表达居民沟通、公共空间、环境巡检与到家服务。
- 四幅场景以等宽单元打包为一张 `4096×576` AVIF 横向图带，每个场景窗口为 `1024×576`。
- 页面通过四个独立裁切窗口显示图带中的不同区域，避免重复使用同一构图。
- AVIF 文件保持约 50 KB，减少四张独立高清图片带来的重复请求和带宽开销。
- 继续保留原有 `assets/community.webp` 作为不支持 AVIF 浏览器的降级资源。

## 页面位置

1. 首屏：物业人员与居民沟通。
2. 重点案例：社区公共空间与居民活动。
3. 住宅社区案例：环境巡检。
4. 旧改社区案例：物业人员协助居民。

## 加载策略

- 首屏图片使用 `fetchpriority="high"`。
- 案例图片使用 `loading="lazy"`。
- 所有图片提供固有宽高，减少页面加载时的布局位移。
- JavaScript 根据 `currentSrc` 判断是否采用 AVIF；回退到 WebP 时取消图带偏移，确保旧浏览器仍能正常显示。

## 约束

- 不引入 CDN、外部图床、前端框架或构建依赖。
- 不修改既有章节 ID、导航和核心业务文案。
- EdgeOne 继续从仓库根目录复制静态文件，无需修改现有构建命令。
- 当前图片属于官网视觉演示素材，正式商用前仍应优先替换为获得授权的泰典物业真实项目照片。
