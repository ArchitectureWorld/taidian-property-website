# A｜社区生命网络滚动叙事脚本

## 视觉母题

以持续呼吸、聚合和重组的社区网络作为主视觉。真实图片不是独立页面或突然插入的图库，而是网络背后的“社区记忆层”：随着叙事推进，现实空间逐渐被网络识别、显影，再回到温暖稳定的长期关系。

## 图像编排

> 图像资源统一使用 `assets/community-scenes.avif`：`scene-0` 为服务现场，`scene-1` 为老旧社区肌理，`scene-2` 为现代入口与秩序空间，`scene-3` 为绿化社区与长期生活结果。四个场景作为持续存在的图层交叉混合，不做瞬时替换。

| 资源 | 用途 | 进入方式 | 退场方式 |
|---|---|---|---|
| `assets/community-scenes.avif#scene-0` | 序章与经验章节的生活现场 | 从低对比背景中缓慢显影，保持人物与街巷可辨但不压过网络 | 在进入老旧社区章节时，与黑白巷道连续交叉淡化 |
| `assets/community-scenes.avif#scene-1` | 老旧社区章节的空间记忆 | 网络节点向几个社区中心聚合时，黑白图像在同一区域增强 | 随效率路径形成而逐步降低存在感，不突然消失 |
| `assets/community-scenes.avif#scene-2` | 效率价值章节的改善结果 | 路径变直、连接变短时，从低饱和秩序空间中渐进显现 | 向终章过渡时继续保留为环境纹理 |
| `assets/community-scenes.avif#scene-3` | 长期共建章节的稳定收束 | 与秩序空间长距离交叉混合，亮度逐步提高 | 进入后续内容时与页面背景共同淡出 |

## 001 序章

- 文案任务：建立“泰典物业是一套持续运行的社区服务系统”。
- 动态任务：粒子从松散状态逐步聚合为完整网络。
- 图片任务：`assets/community-scenes.avif#scene-0` 只以约 8%—18% 的强度存在，像被网络感知到的真实日常。
- 连续性：不允许首屏直接呈现清晰大图；图片需要在前 20% 滚动距离内缓慢增强。

## 002 经验

- 文案任务：解释经验最终体现为更早做对判断。
- 动态任务：网络层级变清楚，核心节点稳定。
- 图片任务：继续使用 `assets/community-scenes.avif#scene-0`，通过轻微推近而不是换图维持连续性。
- 连续性：序章与经验使用同一图片，避免第一处章节边界出现切换感。

## 003 老旧社区

- 文案任务：展示对复杂既有社区关系的理解。
- 动态任务：网络聚合到多个局部中心，表达楼栋、居民、设施和服务点的复杂关系。
- 图片任务：从 `assets/community-scenes.avif#scene-0` 平滑交叉到 `assets/community-scenes.avif#scene-1`；交叉区间覆盖完整章节过渡，不使用瞬时切换。
- 连续性：黑白巷道先以低透明度叠在原图上，再逐渐成为主图。

## 004 效率价值

- 文案任务：解释减少重复、等待和无效投入的高性价比逻辑。
- 动态任务：节点从复杂簇群转为更短、更清晰的路径。
- 图片任务：由 `assets/community-scenes.avif#scene-1` 过渡到 `assets/community-scenes.avif#scene-2`；图片强度略低于网络，让路径仍然是主角。
- 连续性：黑白到彩色通过明暗与图层权重同步变化完成，不允许背景颜色突然翻转。

## 005 长期共建

- 文案任务：形成长期合作与日常安心的品牌收束。
- 动态任务：网络形成稳定环形结构并降低运动幅度。
- 图片任务：`assets/community-scenes.avif#scene-2` 与 `assets/community-scenes.avif#scene-3` 长距离融合，最终获得更明亮、稳定的生活空间感。
- 连续性：进入后续普通内容前，图片、网络和文字使用同一退场进度共同淡出。

## 连续性规则

1. 四张图片始终通过 `sequenceWeights()` 和 `interpolateKeyframes()` 连续混合，不使用 `display:none`、瞬时 class 切换或不透明度跳变。
2. 相邻图片保持完整章节过渡区间；同一章节可延续上一张图片以减少切换频率。
3. 图片、网络、文字、章节编号和进度条全部由同一个 `displayProgress` 驱动。
4. 图片只做缓慢推近、轻微横移与明暗变化，不使用大幅位移或突兀缩放。
5. 所有图像退场必须与下一张图或页面背景同时发生，不出现空白断层。

## 性能规则

- 图片使用本地 AVIF 精灵图，四个场景只解码一次。
- 图片仅更新 `opacity` 与 `transform`，不在滚动过程中执行昂贵滤镜动画。
- Canvas DPR 桌面端限制为 1.5，移动端限制为 1.25。
- 滚动事件只更新目标进度，实际绘制由 `requestAnimationFrame` 完成。
- 动画稳定后停止重绘，并支持 `prefers-reduced-motion`。
