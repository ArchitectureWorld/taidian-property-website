# C｜真实社区数字图层滚动叙事脚本

## 视觉母题

真实社区始终是主舞台，数字节点和路径只是解释服务逻辑的透明图层。图片切换必须像镜头运动和空间连续转场，而不是传统轮播：上一张图在退场时仍保留部分纹理，下一张图同时从相近构图和明暗中接管画面。

## 图像编排

> 图像资源统一使用 `assets/community-scenes.avif`：`scene-0` 为服务现场，`scene-1` 为老旧社区肌理，`scene-2` 为现代入口与秩序空间，`scene-3` 为绿化社区与长期生活结果。四个场景作为持续存在的图层交叉混合，不做瞬时替换。

| 资源 | 用途 | 进入方式 | 退场方式 |
|---|---|---|---|
| `assets/community-scenes.avif#scene-0` | 序章与经验章节的真实服务现场 | 首屏直接作为主图，但从较暗、较低饱和状态逐步恢复 | 与黑白巷道在同一滚动区间交叉淡化 |
| `assets/community-scenes.avif#scene-1` | 老旧社区章节的真实空间肌理 | 从服务场景的树荫和街巷方向中自然接管 | 在效率价值章节中逐渐被现代入口与数字路径覆盖 |
| `assets/community-scenes.avif#scene-2` | 效率价值章节的秩序与响应路径 | 随数字路径变清晰而逐步增强暖光和材质 | 与绿化社区图长距离融合 |
| `assets/community-scenes.avif#scene-3` | 长期共建章节的生活结果 | 从入口空间平滑过渡到更完整的社区生活环境 | 与终章背景共同保持到页面退场结束 |

## 001 序章

- 文案任务：说明科技不是遮住生活，而是更清楚地看见生活。
- 动态任务：少量服务节点建立初始连接，扫描线缓慢移动。
- 图片任务：`assets/community-scenes.avif#scene-0` 是主画面，初始略暗、低饱和，随滚动轻微推近。
- 连续性：首屏不使用入场闪白或突然加载，图片在页面首次绘制时即存在。

## 002 经验

- 文案任务：说明经验帮助服务在问题扩大前先一步抵达。
- 动态任务：部分节点提前点亮，路径由模糊变清晰。
- 图片任务：继续使用 `assets/community-scenes.avif#scene-0`，仅改变焦点和画面位置。
- 连续性：第一、第二章不换图，以相同真实服务现场建立信任。

## 003 老旧社区

- 文案任务：表达尊重原有生活痕迹，只改善真实难点。
- 动态任务：节点重新分布到楼栋、设施和通行路径。
- 图片任务：从 `assets/community-scenes.avif#scene-0` 平滑过渡到 `assets/community-scenes.avif#scene-1`；黑白图先以低透明度叠加，再逐步成为主体。
- 连续性：过渡期间数字节点不消失，而是重新定位，为两张图建立统一空间关系。

## 004 效率价值

- 文案任务：减少重复与等待，让投入沿清晰路径抵达问题。
- 动态任务：服务路径收敛，流动光点速度略微提高但保持克制。
- 图片任务：由 `assets/community-scenes.avif#scene-1` 交叉到 `assets/community-scenes.avif#scene-2`，彩色与暖光随着路径效率提升逐步恢复。
- 连续性：图片的色彩恢复和节点路径优化同步进行。

## 005 长期共建

- 文案任务：把科技留在后台，把安心交给社区。
- 动态任务：数字节点减少亮度并趋于稳定，表明系统进入日常运行状态。
- 图片任务：`assets/community-scenes.avif#scene-2` 与 `assets/community-scenes.avif#scene-3` 长距离融合，最终把视觉重心交还给真实社区生活。
- 连续性：数字图层不突然关闭，而是逐渐降低对比度；图片保留至整个固定舞台退场完成。

## 连续性规则

1. 图片序列为 `service → service → old lane → modern entrance → green path`，前两章使用同一张图。
2. 所有图片通过 `sequenceWeights()` 连续混合，任意时刻权重总和为 1。
3. 图像推近、横移、节点重排、扫描线和文案交接均使用同一个 `displayProgress`。
4. 数字图层在图片过渡期间始终存在，承担空间锚点和视觉桥梁。
5. 不使用自动轮播、瞬时 class 切换或整屏闪白。

## 性能规则

- 四个场景统一使用本地 AVIF 精灵图，避免外部图床并减少重复解码。
- 图片仅动画 `opacity` 与 `transform`，不持续动画 `filter`。
- 数字节点采用轻量 2D Canvas，光晕使用缓存纹理。
- 滚动事件仅更新目标进度，渲染统一由 `requestAnimationFrame` 完成。
- 支持 `prefers-reduced-motion`，低动态模式保持完整内容可读。
