# C｜真实社区数字图层滚动叙事

## 视觉母题

以真实住宅社区为主画面，在其上叠加克制的服务节点、路径流光、扫描线和状态信息，表达科技用于看见问题和提高效率，而不是遮住生活。

## 全视口结构

页面采用真正的 **全视口滚动叙事舞台**：真实社区图像覆盖完整浏览器窗口，不存在外层展示背景、灰色底板、居中的设备卡片、全站圆角外框或悬浮阴影。

中文文案通过与照片自然融合的暗部渐变保持可读性；导航、数字服务网络、HUD 和章节进度全部直接叠加在同一个社区场景中，不形成独立矩形内容卡片。

## 五章叙事

1. 序章：让真实社区与数字服务图层建立关系；
2. 经验：异常信号被提前识别；
3. 老旧社区：巡查、处理和复盘形成持续修复路径；
4. 效率价值：人员、时间和预算沿更清晰路径抵达问题；
5. 长期共建：科技留在后台，稳定服务回到居民日常。

## 交互要求

- 滚动连续控制图像景深、服务节点、路径、文案和章节；
- 向上滚动可连续倒放；
- 图像与数字图层使用同一阻尼显示进度；
- 最终场景与绿色终章背景连续交接，不出现硬切。
