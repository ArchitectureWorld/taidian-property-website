# A｜社区生命网络滚动叙事

## 视觉母题

以粒子、连接线、暖色服务节点和缓慢重组的网络体表达社区不是静态建筑集合，而是一套由居民、空间、设施和服务共同组成的生命系统。

## 全视口结构

页面采用真正的 **全视口滚动叙事舞台**：浏览器窗口就是网页本身，不存在外层展示背景、灰色底板、居中的设备卡片、全站圆角外框或悬浮阴影。

顶部导航、中文文案、社区生命网络、章节编号和底部进度直接共享同一页面空间。左侧仅使用与页面自然融合的渐变提高文字可读性，不形成独立内容卡片。

## 五章叙事

1. 序章：网络从松散关系进入可识别的社区系统；
2. 经验：连接层级趋于稳定，表达经验形成判断结构；
3. 老旧社区：复杂节点被重新理解与梳理；
4. 效率价值：路径缩短、冗余减少，说明更高性价比；
5. 长期共建：所有关系形成稳定、持续运行的网络。

## 交互要求

- 滚动进度是唯一叙事时间轴；
- 向上滚动连续倒放；
- 阻尼显示进度控制文字、Canvas、章节和背景；
- 五章之间连续插值，不出现突然换页；
- 固定舞台退场时与终章背景连续交接。
