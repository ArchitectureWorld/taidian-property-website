# 真实社区数字图层滚动叙事概念

## 定位

本分支是泰典物业滚动叙事官网的概念 C。真实住宅社区始终是画面主体，数字节点、服务路径和扫描图层只用于揭示物业管理如何在社区日常中持续发生。

## 五章叙事

1. **序章**：从真实社区出发，让服务网络被看见；
2. **经验**：异常信号被更早识别，服务提前抵达；
3. **老旧社区**：保留生活痕迹，持续修复真实难点；
4. **效率价值**：减少重复和等待，让投入沿清晰路径抵达问题；
5. **长期共建**：科技留在后台，稳定服务留在社区日常。

## 交互原则

- 用户滚动推进叙事，向上滚动可以连续倒放；
- 画面通过阻尼平滑追赶滚动目标，不直接绑定原始滚动跳变；
- 中文文案、社区照片运动、数字节点、章节编号和进度条共享同一显示进度；
- 数字叠加必须克制，不能遮住真实社区和居民生活；
- 固定舞台退出时通过透明度、位移、缩放和背景渐变完成连续交接。

## 当前目的

本分支用于判断“真实社区 + 数字图层”能否在保留物业可信度的同时形成高端科技感，不作为正式生产页面，也不在确认前合并到 `main`。
