# 建筑空间模型滚动叙事概念

## 定位

本分支是泰典物业滚动叙事官网的概念 B。动态主体由建筑线框、空间网格、设施节点和服务路径构成，用空间模型表达物业如何理解、梳理并持续运营社区。

## 五章叙事

1. **序章**：建筑、设施、居民和服务路径进入同一空间系统；
2. **经验**：复杂空间形成清晰层级，表达经验转化为判断；
3. **老旧社区**：既有建筑关系被识别、保留并重新梳理；
4. **效率价值**：服务路径缩短，人员与资源更快抵达问题；
5. **长期共建**：每次服务沉淀为下一次判断，形成长期运营模型。

## 交互原则

- 用户滚动推进叙事，向上滚动可以连续倒放；
- 画面通过阻尼平滑追赶滚动目标，不直接绑定原始滚动跳变；
- 中文文案、建筑形态、服务路径、章节编号和进度条共享同一显示进度；
- 按钮只用于定位章节，不替代滚动叙事；
- 固定舞台退出时通过透明度、位移、缩放和背景渐变完成连续交接。

## 当前目的

本分支用于判断“建筑空间模型”是否能够成为泰典物业独有、且具有物业语义的滚动叙事视觉，不作为正式生产页面，也不在确认前合并到 `main`。
