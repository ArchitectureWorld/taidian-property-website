# 社区生命网络滚动叙事概念

## 定位

本分支是泰典物业滚动叙事官网的概念 A。动态主体不是装饰性粒子球，而是由居民、空间、设施与服务关系共同构成的“社区生命网络”。

## 五章叙事

1. **序章**：节点聚合为持续运行的社区系统；
2. **经验**：网络形成稳定层级，表达经验转化为判断；
3. **老旧社区**：复杂节点被识别和重新梳理；
4. **效率价值**：冗余连接减少，服务路径更清晰；
5. **长期共建**：关系汇聚为稳定、长期运行的网络。

## 交互原则

- 用户滚动推进叙事，向上滚动可以连续倒放；
- 画面通过阻尼平滑追赶滚动目标，不直接绑定原始滚动跳变；
- 中文文案、粒子形态、章节编号和进度条共享同一显示进度；
- 按钮只用于定位章节，不替代滚动叙事；
- 固定舞台退出时通过透明度、位移、缩放和背景渐变完成连续交接。

## 当前目的

本分支用于判断“社区生命网络”是否适合作为泰典物业的核心数字品牌视觉，不作为正式生产页面，也不在确认前合并到 `main`。
