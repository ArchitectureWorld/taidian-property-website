# B｜建筑空间模型滚动叙事

## 视觉母题

以建筑线框、坐标网格、楼栋体块和服务路径表达泰典物业对住宅社区空间关系的理解。科技感来自空间模型随滚动被读取、梳理和重新组织，而不是来自传统数据大屏。

## 全视口结构

页面采用真正的 **全视口滚动叙事舞台**：建筑模型直接延伸至浏览器边缘，不存在外层展示背景、灰色底板、居中的设备卡片、全站圆角外框或悬浮阴影。

中文文案、导航、模型坐标和章节进度作为同一空间系统中的信息图层叠加，不再使用“左侧卡片 + 右侧卡片”的分屏结构。

## 五章叙事

1. 序章：建立社区空间系统；
2. 经验：模型层级清晰，形成更快的判断；
3. 老旧社区：既有建筑关系被重新梳理；
4. 效率价值：服务路径收敛，人员和资源更快抵达问题；
5. 长期共建：每次服务沉淀为下一次空间运营判断。

## 交互要求

- 滚动进度连续控制建筑体块、视角、文案和章节；
- 快速滚动通过阻尼平滑追赶；
- 向上滚动可连续倒放；
- 模型与终章空间连续过渡，不发生背景硬切。
